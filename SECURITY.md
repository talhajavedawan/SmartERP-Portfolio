# Security and confidentiality

## Portfolio policy

This repository contains documentation and clean-room sample code only. It intentionally excludes production source, credentials, connection strings, customer or employee information, database contents, internal URLs, commercial documents, and confidential business rules.

If you believe sensitive information has been published here, please report it privately to the repository owner rather than opening a public issue.

## Secure engineering principles demonstrated

- No secrets committed to source control.
- No production endpoints or identifying infrastructure details.
- Explicit validation of domain operations.
- Least-privilege and managed-secret recommendations in the target architecture.
- Automated build and test execution for portfolio code.

## Production access

The original commercial implementation is private and is not available through this repository. Access cannot be provided through public issues or pull requests.
